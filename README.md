# Akustik kamera darslari

Akustik kamera (mikrofon massivi va beamforming) qanday ishlashini tushuntiruvchi interaktiv modellar.

| Dars | Mavzu |
| --- | --- |
| [1-dars](dars-1/) | Tovush qanday tarqaladi |
| [2-dars](dars-2/) | Mikrofon nimani o‘lchaydi |
| [3-dars](dars-3/) | Nega ikki mikrofon har xil vaqtda eshitadi |
| [4-dars](dars-4/) | Vaqt farqini qanday o‘lchaymiz |

Statik sayt: build kerak emas, Vercel'da to'g'ridan-to'g'ri ishlaydi.
